# book-log 작업 규칙
- 스택: Spring Boot 3.4 / Java 21 / JPA / PostgreSQL(Supabase), 프론트는 frontend/
- 사용자는 방향을 정하고 결과를 이해·기록하는 역할. 코드는 Claude가 작성.
- 세션당 기능 1개만. 범위 밖 수정 금지, 발견한 문제는 tasks 파일 "발견 사항"에 적기만 할 것.
- 작업 시작 전 .claude/decisions.md와 해당 tasks/*.md를 먼저 읽을 것.
- 어려운 개념(N+1, Jackson 직렬화 등)은 코드 주석이 아니라 완료 보고에서 2~3줄로 설명.
- 작업 완료 시 tasks 파일 하단에 아래 형식으로 정리:
  1. 문제 상황 2. 고려한 선택지(2~3개) 3. 선택 이유(트레이드오프) 4. 막혔던 부분과 해결
  (노션 트러블슈팅에 그대로 옮길 것이므로 짧게, 면접에서 설명 가능한 수준)
- 정리 뒤에 복습 질문 2~3개 (방금 기능 1~2개 + 기존 코드 연결 1개)
- 테스트: 변경 후 ./gradlew test 실행하고 결과 보고
